# Data

`agent_events.csv` is generated by `src/generate_traces.py`. It contains only synthetic, content-free runtime metadata.

| Field | Description |
|---|---|
| `session_id` | Synthetic multi-agent session identifier |
| `step` | Event order |
| `total_steps` | Total event count in the session |
| `agent` | Agent role producing the event |
| `action` | Runtime action category |
| `tool` | Tool invoked, or `none` |
| `latency_ms` | Synthetic action latency |
| `data_volume_kb` | Synthetic data movement volume |
| `permission_level` | Numeric permission tier from 0 to 3 |
| `external_destination` | Whether data or control crosses the trusted boundary |
| `error_flag` | Whether the action raised an error |
| `label` | Benign or synthetic compromise type |
